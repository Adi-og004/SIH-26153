# Persistence hypothesis test — artifacts

Generated by `python src/run_persistence_hypothesis.py`, verified by
`python src/verify_persistence_hypothesis.py` (11/11 PASS).
Full write-up: [`docs/PERSISTENCE_HYPOTHESIS.md`](../../docs/PERSISTENCE_HYPOTHESIS.md).

Analysis only — no model, threshold, scaler, split or label was modified. Every overall F1
reproduces Task 3 exactly; every confusion matrix reproduces Task 4 exactly.

**The question:** the benchmark target `A(t+k)` is highly autocorrelated with `A(t)`, so
persistence is correct on every window that does not change state. These tables separate
**persistent-state prediction** from **transition prediction**.

| File | Contents |
|---|---|
| `persistence_statistics.csv` | `P(A(t+k)=A(t))`, attack/benign persistence, onset/offset rates, transition counts |
| `transition_decomposition.csv` | Every window classified PP / ONSET / OFFSET / AA, per model and horizon |
| `transition_model_performance.csv` | Accuracy and probability statistics per category; F1/AUC marked unavailable on single-class categories |
| `persistence_excess.csv` | Overall vs persistent-subset vs transition-subset F1/AUC/accuracy |
| `transition_only_metrics.csv` | Transition-conditioned **diagnostic** (not a benchmark score), with base-rate expectations |
| `onset_transition_analysis.csv` | Per-onset warning behaviour, including whether the lookback is clean benign |
| `offset_transition_analysis.csv` | Symmetric analysis at attack offsets |
| `v4_k1_to_k5_correction_decomposition.csv` | Where V4's K=1→K=5 false-negative reduction occurs (phases defined before counting) + target-aligned pairing |
| `pre_transition_signal.csv` | Pre-transition probability vs a deep-persistent baseline |
| `current_state_conditioning.csv` | Model behaviour conditioned on `A(t)=0` and `A(t)=1` |
| `shuffle_diagnostic.csv` | Exploratory prevalence-preserving shuffle — null reference for persistence only |
| `persistence_scorecard.csv` | One-page summary across K=1,2,3,5 |
| `figures/` | 6 figures, all generated from these CSVs |

**Two caveats that apply to every table:**
1. Persistence is handed the observed label `A(t)`; V4 and LR receive only features. Its
   accuracy is structural, not something a traffic model gets for free.
2. Only **6–14 transition windows** exist per horizon out of 3,115. Transition-conditioned
   numbers are descriptive; no significance testing is possible.
