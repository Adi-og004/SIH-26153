# Feature-parity artifacts

Generated by `python src/run_feature_parity.py`, verified by
`python src/verify_feature_parity.py` (13/13 PASS).
Full write-up: [`docs/FEATURE_PARITY.md`](../../docs/FEATURE_PARITY.md).

**Status: APPROXIMATE PARITY.** The window aggregation, transforms,
relative-change stage and scaler interface are *exactly* equivalent between the
training and PCAP pipelines — proven by running both real implementations on
identical flow records (18 fixtures, 954 comparisons, 0 mismatches). The
flow-record production layer is *not* exactly equivalent: CICFlowMeter (Java)
and packet reconstruction build flows differently, so numerical equality between
a dataset window and a PCAP window is **not** claimed.
