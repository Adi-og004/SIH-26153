# Error analysis artifacts — Mar-2-2018 held-out day

Generated by `python src/run_error_analysis.py`, verified by
`python src/verify_error_analysis.py`. Full write-up:
[`docs/ERROR_ANALYSIS.md`](../../docs/ERROR_ANALYSIS.md).

Analysis only — no model, threshold, scaler, split or label was modified.
All aggregate metrics reproduce `results/standardized_baseline_comparison.csv` exactly.

| File | Contents |
|---|---|
| `error_events.csv` | One row per evaluated prediction: 3 models × 4 horizons × 3,115 windows (+ LR K=4 secondary). Probabilities stored at **full precision** — V4's scores are packed tightly enough that 6-decimal rounding shifts ROC-AUC by ~3e-4. |
| `attack_episodes.csv` | The 4 ground-truth attack episodes, with the one lacking an observable onset flagged |
| `false_positive_summary.csv` | FP counts, rates, per-hour, run lengths, before/after-attack context buckets |
| `false_negative_summary.csv` | FN counts per model × horizon × episode |
| `onset_analysis.csv` | Per-onset warning behaviour in a fixed 120 s lookback |
| `post_attack_analysis.csv` | Prediction behaviour in the 300 s after each attack offset |
| `error_feature_summary.csv` | Raw (unscaled) feature statistics at time *t* per model/horizon/error type |
| `error_taxonomy.csv` | Operational FP-A..D / FN-A..E categories with evidence; unmatched cases stay `uncertain` |
| `representative_cases.csv` | Median-probability case per dominant failure mode (selection rule stated in the file) |
| `horizon_error_summary.csv` | TP/TN/FP/FN + metrics + error-run statistics by horizon |
| `horizon_evolution.csv` | Recall on attack windows bucketed by time since their own episode onset |
| `lr_probability_shift.csv` | LR probability histogram and threshold-transfer diagnosis |
| `transition_analysis.csv` | Behaviour on label transitions, with base-rate expectations |
| `figures/` | 8 timeline and summary plots |

**Caveat carried through every table:** persistence receives the observed label `A(t)`;
V4 and Logistic Regression receive only features. Its errors are therefore not comparable
one-for-one with theirs.
